# AlertaIntruso - Sistema de Alarme Inteligente por Visão Computacional

**Versão Atual: 6.1.1** (23/03/2026)

## Descrição

O AlertaIntruso é um sistema de alarme inteligente que utiliza visão computacional para detectar intrusos em áreas protegidas. Ele analisa imagens em tempo real e gera alertas quando detecta movimento suspeito.

## Características

- **Detecção de Movimento**: Analisa imagens em tempo real para detectar movimento.
- **Alertas**: Gera alertas quando detecta movimento suspeito.
- **Configuração**: Pode ser configurado para diferentes tipos de alertas e sensibilidade.

## Instalação

O AlertaIntruso pode ser instalado em dispositivos com suporte a visão computacional.
